## Задание 1 - Возраст

Пользователь вводит свой возраст.

Программа должна определить:

- если возраст меньше 18 — вывести Вы несовершеннолетний;
- если возраст 18 или больше — вывести Вы совершеннолетний.

Пример:

```cs
Введите возраст: 16
Вы несовершеннолетний
```

## ⭐ Задание 13 - Калькулятор доставки

Напишите консольную программу, которая рассчитывает стоимость доставки товара.

Пользователь вводит:

- название товара;
- стоимость товара;
- вес товара;
- расстояние доставки;
- номер способа доставки.

Способ доставки:

- 1 — Обычная
- 2 — Экспресс
- 3 — Самовывоз

Правила расчёта:

### Обычная доставка

Стоимость зависит от веса:

```cs
до 1 кг       → 100 рублей
до 5 кг       → 200 рублей
до 10 кг      → 350 рублей
больше 10 кг  → 500 рублей
```

### Экспресс

Стоимость доставки в 2 раза выше обычной.

Если расстояние больше 100 км, добавить 300 рублей.

### Самовывоз

Стоимость доставки равна 0.

**Дополнительное правило**

Если стоимость товара больше 5000 рублей, доставка становится бесплатной.

Программа должна вывести:

```cs
Товар: ...
Стоимость товара: ...
Вес: ...
Расстояние: ...
Способ доставки: ...

Стоимость доставки: ...
Итоговая стоимость: ...
```

Обязательно используйте switch для выбора способа доставки и if/else для расчёта стоимости.

## ⭐ Задание 14 - Система оценки персонажа

Представьте, что вы разрабатываете небольшую систему создания персонажа для игры.

Пользователь вводит:

- имя персонажа;
- возраст;
- расу;
- уровень;
- количество золота;
- выбрал ли персонаж оружие (true/false).

Раса выбирается по номеру:

- 1 — Человек
- 2 — Эльф
- 3 — Гном
- 4 — Орк

Для каждой расы существуют разные бонусы к характеристикам:

- Человек → +10 здоровья
- Эльф    → +20 маны
- Гном    → +15 брони
- Орк     → +20 атаки

Затем программа должна проверить:

- Можно ли создать персонажа такого уровня.
- Доступно ли персонажу оружие.
- Достаточно ли золота для покупки стартового комплекта.
- Какой бонус получает выбранная раса.

Правила:

- персонаж должен быть старше 10 лет;
- уровень должен быть от 1 до 100;
- стартовый комплект стоит 500 золота;
- если уровень больше 50, стоимость комплекта увеличивается до 1000 золота;
- если оружие не выбрано, вывести предупреждение.

В конце программа должна вывести небольшую карточку персонажа:

```cs
========== ПЕРСОНАЖ ==========

Имя: ...
Возраст: ...
Раса: ...
Уровень: ...
Золото: ...
Оружие: ...

Бонус расы: ...

Статус создания: ...
===============================
```

## ⭐ Задание 15 - Мини-банковская система

Напишите консольную программу, имитирующую работу банковского счёта.

Пользователь вводит:

- имя клиента;
- возраст;
- начальный баланс;
- тип счёта.

Тип счёта:

- 1 — Дебетовый
- 2 — Накопительный
- 3 — Премиальный

Затем пользователь выбирает операцию:

```cs
1 — Пополнить счёт
2 — Снять деньги
3 — Проверить баланс
4 — Получить информацию о счёте
```

> Используйте switch.

**Правила пополнения**

Пользователь вводит сумму пополнения.

- сумма должна быть больше 0;
- после пополнения баланс увеличивается.

**Правила снятия**

Пользователь вводит сумму снятия.

- сумма должна быть больше 0;
- нельзя снять больше денег, чем есть на счёте.

Дополнительные ограничения:

- если клиент младше 18 лет, нельзя снять более 5000 рублей за одну операцию;
- если баланс после операции становится меньше 1000 рублей, вывести предупреждение.

**Информация о счёте**

Для разных типов счёта вывести разные сообщения:

```cs
1 → Дебетовый счёт
2 → Накопительный счёт
3 → Премиальный счёт
```

Для премиального счёта вывести дополнительно:

```cs
Вам доступно премиальное обслуживание.
```

В конце программа должна вывести:

```cs
========== БАНК ==========

Клиент: ...
Возраст: ...
Тип счёта: ...
Баланс: ...

Результат операции: ...

==========================
```

Программа должна содержать несколько ветвлений, switch, преобразование введённых чисел через Convert.ToInt32() и арифметические вычисления.
