## Задание 1 - Калькулятор двух чисел

Напишите программу, которая запрашивает у пользователя два целых числа.

Что должна делать программа:

1. Считать два числа с клавиатуры.
2. Преобразовать введённые значения в тип int с помощью Convert.ToInt32().
3. Вычислить сумму, разность и произведение этих чисел.
4. Вывести все результаты на экран.

**Пример**:

```cs
Введите первое число: 12
Введите второе число: 5

Сумма: 17
Разность: 7
Произведение: 60
```

## Задание 2 - Площадь комнаты

Представьте, что вы помогаете сделать ремонт в комнате. Для расчёта количества материалов необходимо узнать площадь и периметр пола.

Напишите программу, которая:

1. Запрашивает длину и ширину комнаты.
2. Преобразует введённые значения в тип double с помощью Convert.ToDouble().
3. Вычисляет площадь комнаты по формуле: **Площадь = длина × ширина**
4. Вычисляет периметр комнаты по формуле: **Периметр = 2 × (длина + ширина)**
5. Выводит оба результата на экран.

**Пример работы программы:**

```cs
Введите длину комнаты: 4.5
Введите ширину комнаты: 3

Площадь комнаты: 13,5
Периметр комнаты: 15
```

## Задание 3 - Отчёт о подготовке к уроку

Напишите программу, которая собирает информацию о подготовке пользователя к занятию.

**Что должна делать программа:**

1. Спросить, выполнено ли домашнее задание. Пользователь вводит true или false.
2. Преобразовать ответ в тип bool с помощью Convert.ToBoolean().
3. Спросить, сколько минут пользователь потратил на подготовку. Преобразовать ответ в int.
4. Перевести минуты в часы, разделив количество минут на 60.0.
5. Вывести введённую информацию и затраченное время в часах.

**Пример работы программы:**

```cs
Домашнее задание выполнено? (true/false)
true

Сколько минут вы потратили на подготовку?
90

Домашнее задание выполнено: True
Время подготовки: 90 минут
Время в часах: 1,5
```

## Задание 4 - Положительное или отрицательное число

Напишите программу, которая запрашивает у пользователя целое число и определяет его знак.

**Требования:**

- Если число больше нуля, вывести «Число положительное».
- Если число меньше нуля, вывести «Число отрицательное».
- Если число равно нулю, вывести «Число равно нулю».

## Задание 5 - Чётное или нечётное

Напишите программу, которая запрашивает целое число и определяет, является ли оно чётным.

**Требования:**

- Если число делится на 2 без остатка, вывести «Число чётное».
- В противном случае вывести «Число нечётное».

> Подсказка: для проверки остатка от деления используется оператор %.

## Задание 6 - Проверка возраста

Для записи на учебный курс необходимо достичь определённого возраста.

Напишите программу, которая запрашивает возраст пользователя.

**Требования:**

- Если пользователю 14 лет или больше, вывести «Вы можете записаться на курс C#».
- Если пользователю меньше 14 лет, вывести «Пока вы не можете записаться на этот курс».

## Задание 7 - Какое число больше?

Напишите программу, которая запрашивает два целых числа и сравнивает их.

**Требования:**

- Если первое число больше второго, вывести «Первое число больше».
- Если второе число больше первого, вывести «Второе число больше».
- Если числа равны, вывести «Числа равны».

## Задание 8 - Оценка за контрольную работу

Учитель выставляет оценку в зависимости от количества набранных баллов. Максимум за контрольную работу — 100 баллов.

Напишите программу, которая запрашивает количество набранных баллов и выводит оценку.

- 90-100 -> 5
- 70-89 -> 4
- 50-69 -> 3
- 0-49 -> 2

Если пользователь ввёл число меньше 0 или больше 100, программа должна вывести сообщение «Некорректное количество баллов».

Подсказка: используйте цепочку if-else if-else.

## Задание 9 - Какой сегодня день?

Напишите программу, которая запрашивает у пользователя число от 1 до 7 и выводит соответствующий день недели.

**Требования:**

1. Считать число с клавиатуры с помощью Console.ReadLine().
2. Преобразовать введённое значение в тип int.
3. С помощью switch-case определить день недели.
4. Если пользователь ввёл число вне диапазона от 1 до 7, вывести сообщение «Некорректный номер дня недели».

**Пример работы программы:**

```cs
Введите номер дня недели: 3

Среда
```

> Подсказка: понедельник — 1, вторник — 2, среда — 3 и так далее, воскресенье — 7.
