## ⭐ Задание 8 - Банковская операция

Создайте метод:

```cs
bool TryWithdraw(
    double balance,
    double amount,
    out double newBalance
)
```

Метод должен попытаться снять деньги со счёта.

Правила:

- сумма должна быть больше 0;
- нельзя снять больше, чем есть на счёте.

Если операция успешна:

**true**

и newBalance должен содержать новый баланс.

Если операция невозможна:

**false**

а newBalance должен сохранить старый баланс.

Пример

```cs
Баланс: 5000
Снятие: 1500

Операция выполнена.
Новый баланс: 3500
```

И:

```cs
Баланс: 5000
Снятие: 7000

Недостаточно средств.
Баланс: 5000
```

Что здесь важно

Обратите внимание на название:

> TryWithdraw

Метод сообщает, удалось ли выполнить операцию, а out возвращает результат.

## ⭐ Задание 9 - Игра «Битва персонажей»

Создайте два метода:

```cs
void Attack(
    ref int health,
    int damage
)
```

и:

```cs
bool IsAlive(int health)
```

Есть два персонажа:

```cs
int playerHealth = 100;
int enemyHealth = 100;
```

Игрок и враг атакуют друг друга.

Каждая атака уменьшает здоровье противника.

Урон можно генерировать через Random, например, от 10 до 30.

Программа должна продолжать бой, пока один из персонажей не погибнет.

После каждой атаки выводить:

```cs
Игрок атакует врага!
Урон: 17
Здоровье врага: 83
```

Затем:

```cs
Враг атакует игрока!
Урон: 22
Здоровье игрока: 78
```

В конце:

```cs
Игрок победил!
```

**Дополнительное усложнение**

Добавьте критический удар:

- обычный урон: 10–20;
- критический: 30–50.

## ⭐ Задание 10 - Мини-система обработки заказа

Представьте, что вы пишете небольшую часть настоящего интернет-магазина.

Создайте метод:

```cs
bool TryCreateOrder(
    double balance,
    double productPrice,
    int quantity,
    out double totalPrice,
    out double remainingBalance
)
```

Метод должен:

- проверить количество товара;
- рассчитать общую стоимость;
- проверить, хватает ли денег;
- если денег хватает — списать стоимость заказа;
- вернуть результат операции.

Правила:

- quantity должен быть больше 0;
- общая стоимость: **productPrice × quantity**
- стоимость не может быть больше баланса.

При успешной покупке:

**true**

totalPrice должен содержать стоимость заказа, а remainingBalance — остаток денег.

При неуспешной:

**false**

Пример

```cs
Баланс: 10000
Цена товара: 1500
Количество: 3

Заказ создан!

Стоимость заказа: 4500
Остаток: 5500
```

Если денег недостаточно:

```cs
Баланс: 3000
Цена товара: 1500
Количество: 3

Не удалось создать заказ.
Недостаточно средств.
```

**Дополнительное усложнение**

Добавьте скидку:

- от 3 товаров → 5%
- от 5 товаров → 10%
- от 10 товаров → 15%

Для расчёта скидки создайте отдельный метод:

> double CalculateDiscount(int quantity)

В итоге программа должна выглядеть примерно концептуально так:

Main

↓

CalculateDiscount

↓

TryCreateOrder
