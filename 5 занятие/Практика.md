## Задание 1 — Паспорт игрового персонажа

Представьте, что вы разрабатываете игру и вам нужно формировать информацию о персонажах.

Создайте метод:

> string CreateCharacterInfo(string name, int level, int health)

Метод должен принимать:

- имя персонажа;
- уровень;
- количество здоровья.

И возвращать строку с информацией о персонаже.

Например:

```cs
CreateCharacterInfo("Arthas", 15, 100)
```

Результат:

```text
========== ПЕРСОНАЖ ==========

Имя: Arthas
Уровень: 15
Здоровье: 100 HP

=============================
```

В `Main()` вызовите метод для нескольких персонажей и выведите полученную информацию.

**Дополнительное усложнение**

Добавьте параметр `int damage` и выведите, сколько урона может нанести персонаж.

## Задание 2 — Калькулятор времени загрузки

Вы разрабатываете программу, которая рассчитывает, сколько времени потребуется для скачивания файла.

Создайте метод:

> double CalculateDownloadTime(double fileSize, double downloadSpeed)

Метод принимает:

- размер файла в мегабайтах;
- скорость интернета в мегабитах в секунду.

Метод должен вернуть время загрузки в секундах.

Формула:

```text
Время = Размер файла * 8 / Скорость интернета
```

Например:

```cs
CalculateDownloadTime(100, 20)
→ 40 секунд
```

Программа должна попросить пользователя ввести размер файла и скорость интернета, вызвать метод и вывести результат.

**Пример:**

```text
Введите размер файла (МБ): 500
Введите скорость интернета (Мбит/с): 50

Время загрузки: 80 секунд
```

**Дополнительное усложнение**

Создайте метод:

> string FormatTime(double seconds)

Метод должен преобразовывать количество секунд в удобный для чтения формат.

Например:

```text
FormatTime(125)
→ 2 минуты 5 секунд
```

## Задание 3 — Управление роботом

Представьте, что вы программируете робота, который перемещается по игровому полю размером `10 × 10`.

Положение робота определяется двумя переменными:

```cs
int x = 5;
int y = 5;
```

Создайте метод:

> void MoveRobot(ref int x, ref int y, char direction)

Метод должен принимать направление движения:

```text
W — вверх
S — вниз
A — влево
D — вправо
```

В зависимости от направления метод должен изменять координаты робота.

Например:

```text
Начальные координаты: (5, 5)

Направление: W
Новые координаты: (5, 4)

Направление: D
Новые координаты: (6, 4)
```

### Правила

- координата `x` не может быть меньше 0 или больше 9;
- координата `y` не может быть меньше 0 или больше 9;
- если робот пытается выйти за пределы поля, его положение не должно изменяться;
- если введено неизвестное направление, вывести сообщение об ошибке.

В `Main()` создайте несколько команд перемещения и проверьте работу робота.

**Главное условие**

Метод должен изменять исходные переменные `x` и `y` через `ref`.

## Задание 4 — Разбор длительности видео

Представьте, что вы разрабатываете видеоплеер.

Внутри программы длительность видео хранится в секундах, но пользователю удобнее видеть её в формате:

```text
Часы : Минуты : Секунды
```

Например:

```text
3671 секунд
```

Должны преобразоваться в:

```text
1 час 1 минута 11 секунд
```

Создайте метод:

> bool TryConvertTime(int totalSeconds, out int hours, out int minutes, out int seconds)

Метод должен:

1. принимать общую длительность в секундах;
2. преобразовывать её в часы, минуты и секунды;
3. возвращать `true`, если преобразование выполнено успешно;
4. возвращать `false`, если передано отрицательное количество секунд.

Результаты преобразования необходимо передать через `out`.

**Пример использования:**

```cs
int totalSeconds = 3671;

bool success = TryConvertTime(
    totalSeconds,
    out int hours,
    out int minutes,
    out int seconds
);
```

Результат:

```text
Преобразование выполнено!

Часы: 1
Минуты: 1
Секунды: 11
```

Если передано отрицательное число:

```text
Ошибка: длительность не может быть отрицательной.
```

**Дополнительное условие**

Попробуйте самостоятельно разобраться, почему переменные `hours`, `minutes` и `seconds` необходимо обязательно заполнить внутри метода даже в случае, если преобразование выполнить не удалось.

## ⭐ Задание 5 — Система управления парковкой

Представьте, что вы разрабатываете программное обеспечение для автоматической парковки.

На парковке есть определённое количество свободных мест.

Создайте переменную:

```cs
int freePlaces = 10;
```

Стоимость одного часа парковки:

```cs
int pricePerHour = 200;
```

Программа должна поддерживать три операции:

```text
1 — Припарковать автомобиль
2 — Освободить парковочное место
3 — Показать информацию о парковке
```

### Часть 1. Парковка автомобиля

Создайте метод:

> bool TryPark(ref int freePlaces, int hours, int pricePerHour, out int totalPrice)

Метод должен:

1. Проверить, есть ли свободные места.
2. Проверить, что количество часов больше 0.
3. Если парковка возможна, уменьшить количество свободных мест на 1.
4. Рассчитать стоимость парковки.
5. Вернуть `true`, если автомобиль успешно припаркован.
6. Вернуть `false`, если припарковать автомобиль невозможно.

Стоимость парковки рассчитывается следующим образом:

```text
Стоимость = Количество часов * Стоимость одного часа
```

Если операция не выполнена, `totalPrice` должен быть равен 0.

### Часть 2. Освобождение парковочного места

Создайте метод:

> void LeaveParking(ref int freePlaces, int totalPlaces)

Метод должен увеличивать количество свободных мест на 1.

Однако количество свободных мест не может превышать общее количество мест на парковке.

### Часть 3. Информация о парковке

Создайте метод:

> void PrintParkingInfo(int freePlaces, int totalPlaces)

Метод должен выводить:

```text
======= ПАРКОВКА =======

Всего мест: 10
Свободно: 7
Занято: 3

========================
```

### Главное меню

В `Main()` реализуйте меню:

```text
======= ПАРКОВКА =======

1 — Припарковать автомобиль
2 — Освободить место
3 — Показать информацию
0 — Завершить программу

Ваш выбор:
```

В зависимости от выбора пользователя вызывайте соответствующие методы.

### Пример работы

```text
======= ПАРКОВКА =======

Свободных мест: 10

1 — Припарковать автомобиль
2 — Освободить место
3 — Показать информацию
0 — Завершить программу

Ваш выбор: 1

На сколько часов припарковать автомобиль?
5

Автомобиль успешно припаркован!

Стоимость: 1000 рублей
Свободных мест: 9
```

### Требования

В этом задании обязательно должны использоваться:

- `void` — для методов, которые только выполняют действие;
- `return` — для возврата результата;
- `ref` — для изменения количества свободных мест;
- `out` — для передачи стоимости парковки;
- параметры методов.

- клиент с абонементом получает скидку 20%.
