## Задание 1 - Числа от 1 до N

Пользователь вводит число N.

Выведите все числа от 1 до N.

**Пример:**

Введите N: 7

```cs
1
2
3
4
5
6
7
```

> Используйте цикл for.

**Бонусные усложнения**
Выводить только числа, которые делятся одновременно на 3 и 5.

## Задание 3 - Сумма чисел

Пользователь вводит число N.

Программа должна найти сумму всех чисел от 1 до N.

**Пример:**

```cs

```

Потому что:

1 + 2 + 3 + 4 + 5 = 15

**Бонусные усложнения**

Кроме суммы вывести:

- количество чисел;
- среднее арифметическое;
- произведение всех чисел.

## Задание 6 - Угадай число

В программе заранее записано секретное число:

```cs
int secretNumber = 42;
```

Пользователь должен вводить числа до тех пор, пока не угадает правильное.

После каждой попытки программа должна сообщать:

- Загаданное число больше;
- Загаданное число меньше;
- Вы угадали!.

> Используйте while.

Пример:

```cs
Введите число: 20
Загаданное число больше
```

```cs
Введите число: 50
Загаданное число меньше
```

```cs
Введите число: 42
Вы угадали!
```

## ⭐ Задание 14 - Анализ оценок

Напишите программу, которая позволяет преподавателю ввести оценки нескольких учеников.

Сначала пользователь вводит количество учеников.

Затем для каждого ученика программа запрашивает оценку от 1 до 5.

Программа должна:
- посчитать количество пятёрок;
- посчитать количество четвёрок;
- посчитать количество троек;
- посчитать количество двоек;
- посчитать количество единиц;
- вычислить среднюю оценку;
- определить количество неудовлетворительных оценок.

После завершения ввода вывести отчёт:

```cs
========== ОТЧЁТ ==========

Количество учеников: 10

5: 3
4: 4
3: 2
2: 1
1: 0

Средняя оценка: 4.0
Неудовлетворительных: 1

===========================
```

Если пользователь вводит неправильную оценку:

Оценка должна быть от 1 до 5.

Такую оценку не нужно учитывать.

> Для решения задачи понадобится цикл и несколько переменных-счётчиков.


## ⭐ Задание 15 - Мини-игра «Камень, ножницы, бумага»

Напишите консольную игру «Камень, ножницы, бумага».

В каждом раунде:

Пользователь выбирает:

1 — Камень
2 — Ножницы
3 — Бумага

Компьютер выбирает случайное число от 1 до 3.

Используйте:

```cs
Random random = new Random();
```

и:

```cs
random.Next(1, 4);
```

После каждого раунда программа должна определить:

- победил игрок;
- победил компьютер;
- ничья.

И вести счёт:

- Побед игрока: 2
- Побед компьютера: 1
- Ничьих: 3

### Главное меню

Перед каждым раундом выводите:

```cs
===== КАМЕНЬ, НОЖНИЦЫ, БУМАГА =====

1 — Камень
2 — Ножницы
3 — Бумага
0 — Выйти из игры

Ваш выбор:
```

Если пользователь вводит 0, игра должна завершиться с помощью break.

Если пользователь вводит неправильный вариант:

```cs
Неверный выбор.
```

и следующий раунд не должен начинаться.

> Для этого используйте continue.

После выхода из игры выведите итоговый результат:

```cs
========== РЕЗУЛЬТАТ ==========

Побед игрока: 5
Побед компьютера: 3
Ничьих: 2

Спасибо за игру!

===============================
```

**Бонусные усложнения**

Игра должна продолжаться до тех пор, пока один из игроков не наберёт 5 побед.

При этом пользователь всё ещё должен иметь возможность завершить игру вручную через 0.
