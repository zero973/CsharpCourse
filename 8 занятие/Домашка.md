## Задание 1 — Аудиоплеер

Представьте, что вы разрабатываете программную часть аудиоплеера.

Создайте класс:

> AudioPlayer

У плеера должны быть закрытые поля:

- `_volume` — громкость от 0 до 100;
- `_isMuted` — выключен ли звук.

Создайте публичные свойства для получения текущей громкости и состояния звука. Напрямую изменять эти значения из `Main()` нельзя.

Конструктор должен устанавливать начальные значения:

```text
Громкость: 50%
Звук включён.
```

Создайте методы:

> bool SetVolume(int volume)

Устанавливает громкость.

- допустимый диапазон: 0–100;
- при некорректном значении громкость не изменяется;
- возвращает результат операции.

> void IncreaseVolume(int value)

Увеличивает громкость на указанное значение.

> void DecreaseVolume(int value)

Уменьшает громкость на указанное значение.

> void Mute()

Выключает звук.

> void Unmute()

Включает звук.

> void PrintInfo()

Выводит информацию о плеере.

### В `Main()`:

1. Создайте два аудиоплеера.
2. Измените громкость первого.
3. Выключите на нём звук.
4. Попробуйте установить громкость 150.
5. Включите звук обратно.
6. Выведите информацию об обоих плеерах.

**Дополнительное усложнение**

Добавьте метод:

> void ToggleMute()

Он должен переключать состояние звука: если звук включён — выключать, если выключен — включать.

## Задание 2 — Склад интернет-магазина

Представьте, что вы разрабатываете систему учёта товаров на складе.

Создайте класс:

> InventoryItem

У товара должны быть закрытые поля:

- `_name` — название товара;
- `_price` — цена;
- `_quantity` — количество на складе.

Создайте публичные свойства для получения информации о товаре.

Создайте конструктор, который принимает название, цену и начальное количество товара.

Создайте методы:

> bool AddStock(int amount)

Добавляет товары на склад.

- количество должно быть больше нуля;
- если передано некорректное значение, операция не выполняется.

> bool Sell(int amount)

Продаёт указанное количество товаров.

Правила:

- количество должно быть больше нуля;
- нельзя продать больше товаров, чем находится на складе;
- при успешной продаже количество уменьшается.

> bool ChangePrice(double newPrice)

Изменяет стоимость товара.

- новая цена должна быть больше нуля;
- при некорректной цене стоимость не изменяется.

> void PrintInfo()

Выводит информацию о товаре.

### В `Main()`:

1. Создайте три товара.
2. Добавьте несколько товаров на склад.
3. Продайте часть товаров.
4. Попробуйте продать больше товаров, чем имеется на складе.
5. Измените стоимость одного товара.
6. Выведите информацию обо всех товарах.

**Пример:**

```text
======= ТОВАР =======

Название: Монитор
Цена: 15000
Количество: 10

Стоимость всех товаров на складе: 150000

====================

Продано 3 монитора.
Остаток: 7

Не удалось выполнить продажу.
Недостаточно товара на складе.
```

**Дополнительное усложнение**

Добавьте метод:

> double CalculateWarehouseValue()

Он должен возвращать общую стоимость всех товаров на складе.

## ⭐ Задание 3 — Космический корабль

Представьте, что вы разрабатываете игру, в которой игрок управляет космическим кораблём.

Создайте класс:

> SpaceShip

У корабля должны быть следующие закрытые поля:

- `_name` — название корабля;
- `_health` — прочность корпуса;
- `_shield` — уровень щита;
- `_fuel` — количество топлива.

Создайте публичные свойства для получения информации о корабле.

Создайте конструктор, который принимает название корабля.

Начальные характеристики:

```text
Прочность корпуса: 100
Щит: 100
Топливо: 100
```

Максимальное значение каждой характеристики — 100.

Создайте методы:

> void TakeDamage(int damage)

Наносит кораблю урон.

Правила:

1. Урон сначала поглощается щитом.
2. Если урона больше, чем осталось щита, оставшийся урон получает корпус.
3. Ни щит, ни прочность корпуса не могут стать отрицательными.
4. Если прочность корпуса равна 0, корабль уничтожен.

Например:

```text
Щит: 20
Прочность: 100
Урон: 50

Новый щит: 0
Новая прочность: 70
```

> bool Refuel(int amount)

Заправляет корабль.

Правила:

- количество топлива должно быть больше нуля;
- топливо не может превышать 100;
- если заправка невозможна, метод возвращает `false`.

> bool Repair(int amount)

Восстанавливает прочность корпуса.

Правила:

- количество восстановления должно быть больше нуля;
- прочность не может превышать 100;
- уничтоженный корабль нельзя починить.

> bool Launch(int fuelCost)

Пытается запустить корабль.

Правила:

- топлива должно хватать для запуска;
- корабль не должен быть уничтожен;
- если запуск успешен, топливо уменьшается на `fuelCost`;
- метод возвращает `true`, если запуск выполнен успешно.

> void PrintInfo()

Выводит информацию о корабле.

### В `Main()`:

1. Создайте два космических корабля.
2. Нанесите одному кораблю урон.
3. Проверьте состояние щита и корпуса.
4. Попробуйте запустить корабль.
5. Заправьте его.
6. Почините корпус.
7. Попробуйте запустить корабль повторно.
8. Выведите информацию об обоих кораблях.

**Пример:**

```text
======= КОСМИЧЕСКИЙ КОРАБЛЬ =======

Название: Enterprise

Корпус: 70 / 100
Щит: 0 / 100
Топливо: 40 / 100

==================================

Корабль получил 50 единиц урона!

Щит поглотил 20 единиц.
Корпус получил 30 единиц урона.

Корпус: 70
Щит: 0

Запуск невозможен!
Недостаточно топлива.

Корабль заправлен!
Новое количество топлива: 100

Корабль успешно запущен!

```

**Главное условие**

Все поля должны быть `private`.

Изменять характеристики корабля можно только через публичные методы, которые самостоятельно контролируют корректность операций.

Попробуйте в `Main()` напрямую изменить здоровье, щит или топливо. Объясните, почему это невозможно.
