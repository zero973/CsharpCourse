## Задание 1 — Электронная библиотека

На прошлом занятии вы создавали класс `Book`, который хранил информацию о книге.

Однако у такого класса есть проблема: любой другой код может изменить его данные напрямую.

Например:

```cs
Book book = new Book();

book.Title = "";
book.Pages = -500;
```

Это не очень хорошо. Давайте исправим ситуацию.

Создайте класс:

> LibraryBook

У книги должны быть следующие закрытые поля:

- `_title` — название;
- `_author` — автор;
- `_pages` — количество страниц;
- `_isBorrowed` — выдана ли книга читателю.

Создайте публичные свойства для получения информации о книге. Изменять закрытые поля напрямую из `Main()` нельзя.

Создайте конструктор, который принимает название, автора и количество страниц.

Создайте методы:

> bool Borrow()

Выдаёт книгу читателю.

- если книга уже выдана, вернуть `false`;
- если книга свободна, изменить её состояние и вернуть `true`.

> bool ReturnBook()

Возвращает книгу в библиотеку.

- если книга уже находится в библиотеке, вернуть `false`;
- если книга была выдана, изменить её состояние и вернуть `true`.

> void PrintInfo()

Выводит информацию о книге.

### В `Main()`:

1. Создайте две книги.
2. Попробуйте выдать первую книгу.
3. Попробуйте выдать её повторно.
4. Верните книгу.
5. Ещё раз выведите информацию о ней.

**Пример:**

```text
======= КНИГА =======

Название: Гарри Поттер
Автор: Джоан Роулинг
Страниц: 500
Статус: Свободна

=====================

Книга успешно выдана!

Не удалось выдать книгу.
Она уже находится у читателя.

Книга успешно возвращена!
```

**Дополнительное условие**

Попробуйте обратиться из `Main()` напрямую к полю `_isBorrowed` и изменить его.

Объясните, почему компилятор не позволяет это сделать.

## Задание 2 — Умная лампа

Представьте, что вы разрабатываете программное обеспечение для умного дома.

Создайте класс:

> SmartLamp

У лампы должны быть следующие закрытые поля:

- `_isOn` — включена ли лампа;
- `_brightness` — яркость лампы от 0 до 100.

Создайте публичные свойства, позволяющие получать информацию о состоянии лампы, но не изменять её напрямую.

Создайте конструктор, который устанавливает начальные значения:

```text
Лампа выключена.
Яркость: 50%
```

Создайте методы:

> void TurnOn()

Включает лампу.

> void TurnOff()

Выключает лампу.

> bool SetBrightness(int brightness)

Устанавливает яркость лампы.

Правила:

- яркость не может быть меньше 0;
- яркость не может быть больше 100;
- если передано недопустимое значение, яркость не изменяется;
- метод возвращает `true`, если яркость успешно установлена, и `false` в противном случае.

> void PrintInfo()

Выводит информацию о лампе.

### В `Main()`:

1. Создайте две лампы.
2. Включите первую лампу.
3. Измените её яркость.
4. Попробуйте установить яркость 150%.
5. Выключите вторую лампу.
6. Выведите информацию об обеих лампах.

**Пример:**

```text
======= УМНАЯ ЛАМПА =======

Состояние: Включена
Яркость: 75%

==========================

Не удалось изменить яркость.
Допустимый диапазон: 0–100.

Лампа выключена.
```

**Дополнительное усложнение**

Добавьте метод:

> void IncreaseBrightness(int value)

Он должен увеличивать яркость на указанное значение, не позволяя превысить 100%.

Аналогично создайте:

> void DecreaseBrightness(int value)

## Задание 3 — Турникет в метро

Представьте, что вы разрабатываете программу управления турникетом в метро.

Создайте класс:

> Turnstile

У турникета должны быть закрытые поля:

- `_isLocked` — заблокирован ли турникет;
- `_passedPeople` — количество людей, прошедших через турникет.

Создайте публичные свойства для получения текущего состояния турникета и количества прошедших людей.

Конструктор должен создавать заблокированный турникет с нулевым количеством прошедших людей.

Создайте методы:

> void InsertTicket()

Имитирует проверку билета.

Если турникет заблокирован, после проверки билета он должен разблокироваться.

Если турникет уже разблокирован, повторная проверка билета не требуется.

> bool Pass()

Имитирует проход человека через турникет.

Правила:

- если турникет заблокирован, человек не может пройти;
- если турникет разблокирован, человек проходит;
- после прохода турникет автоматически блокируется;
- количество прошедших людей увеличивается на 1.

Метод возвращает `true`, если человек успешно прошёл, и `false`, если проход невозможен.

> void PrintInfo()

Выводит информацию о турникете.

### В `Main()`:

1. Создайте турникет.
2. Попробуйте пройти через заблокированный турникет.
3. Приложите билет.
4. Попробуйте пройти.
5. Попробуйте пройти ещё раз без повторного прикладывания билета.
6. Снова приложите билет и пройдите.
7. Выведите статистику.

**Пример:**

```text
======= МЕТРО =======

Попытка прохода...

Проход запрещён!
Турникет заблокирован.

Билет успешно проверен.
Турникет разблокирован.

Проход разрешён!

Проход запрещён!
Необходимо приложить билет.

======= СТАТИСТИКА =======

Прошло людей: 2
Состояние: Заблокирован

==========================
```

**Дополнительное усложнение**

Добавьте метод:

> void ResetStatistics()

Он должен обнулять количество прошедших людей.
