## Задание 1 - Проверка банковской операции через throw

Напишите программу, которая выполняет перевод денег между двумя счетами.

Есть:

```cs
balanceA = 10000
balanceB = 5000
```

Пользователь вводит сумму перевода.

Программа должна проверить:

- сумма перевода должна быть больше 0;
- сумма не должна превышать баланс отправителя.

Если одно из условий нарушено, необходимо самостоятельно создать исключение с помощью throw.

Например:

```cs
throw new Exception("Сумма перевода должна быть больше нуля.");
```

или:

```cs
throw new Exception("Недостаточно средств.");
```

Затем исключение должно быть обработано через catch.

Пример успешной операции

```cs
Баланс отправителя: 10000
Баланс получателя: 5000

Введите сумму перевода: 3000

Перевод выполнен!

Баланс отправителя: 7000
Баланс получателя: 8000
```

Пример ошибки

```cs
Баланс отправителя: 10000
Баланс получателя: 5000

Введите сумму перевода: 15000

Ошибка: недостаточно средств.
```

**Дополнительное усложнение**

Вынесите проверку и выполнение операции в отдельный метод:

```cs
Transfer(...)
```

Метод должен:

- проверять входные данные;
- при нарушении правил делать throw;
- при успешной операции изменять балансы.

В Main() используйте:

- try
- catch
- finally

Например, в finally выведите:

```cs
Операция завершена.
```

## Задание 2 - Открытие файла

Представьте, что программа пытается открыть файл с сохранёнными данными.

Путь к файлу задаётся в программе: **data.txt**

Попробуйте открыть файл с помощью **File.ReadAllText(...)**.

Программа должна:

- вывести сообщение Открываем файл...;
- открыть файл;
- прочитать его содержимое;
- вывести содержимое на экран;
- вывести сообщение Работа с файлом завершена.

Обработайте ситуацию, когда файла не существует.

В этом случае программа должна вывести:

```cs
Ошибка: файл не найден.
```

**Главное условие**

Используйте конструкцию:

```cs
try
catch
finally
```

В finally выведите:

```cs
Работа с файлом завершена.
```

**Дополнительно**

Попробуйте запустить программу:

- когда файл существует;
- когда файла нет.
