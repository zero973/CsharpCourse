## Задание 1 — Регистрация на игровой турнир

Представьте, что вы разрабатываете программу регистрации игроков на киберспортивный турнир.

Пользователь должен ввести:

- своё имя;
- возраст;
- количество часов, проведённых в игре.

Создайте программу, которая получает эти данные и выводит информацию об игроке.

Однако пользователь может случайно ввести вместо числа текст.

Например:

```text
Введите имя: Alex
Введите возраст: sixteen
```

Программа не должна аварийно завершаться.

### Требования

1. Используйте `try...catch` при преобразовании возраста и количества часов через `Convert.ToInt32()`.
2. Обработайте исключение `FormatException`.
3. Если произошла ошибка, выведите:

```text
Ошибка: необходимо ввести целое число.
Регистрация не выполнена.
```

4. Если все данные введены правильно, выведите карточку игрока.

**Пример успешной регистрации:**

```text
======= ИГРОК =======

Имя: Alex
Возраст: 16
Время в игре: 1200 часов

Регистрация выполнена!

=====================
```

**Дополнительное усложнение**

Обработайте ситуацию, когда пользователь вводит настолько большое число, что оно не помещается в тип `int`. Для этого используйте `OverflowException`.

## Задание 2 — Поиск фильма в каталоге

Представьте, что вы разрабатываете небольшой каталог фильмов.

Есть массив:

```cs
string[] movies =
{
    "Интерстеллар",
    "Начало",
    "Матрица",
    "Побег из Шоушенка",
    "Зелёная миля"
};
```

Пользователь вводит номер фильма, который хочет посмотреть.

Программа должна вывести название выбранного фильма.

Например:

```text
Введите номер фильма: 2

Вы выбрали: Матрица
```

Однако пользователь может ввести неправильные данные.

### Требования

Используйте `try...catch` и обработайте:

- `FormatException` — пользователь ввёл не число;
- `IndexOutOfRangeException` — пользователь указал индекс, которого нет в массиве.

При возникновении ошибки выведите соответствующее сообщение.

Например:

```text
Введите номер фильма: 15

Ошибка: фильма с таким номером нет.
```

**Дополнительное условие**

После завершения операции, независимо от её результата, программа должна вывести:

```text
Запрос к каталогу завершён.
```

Для этого используйте `finally`.

## Задание 3 — Кодовый замок

Вы разрабатываете систему электронного замка.

Правильный код:

```cs
int secretCode = 1234;
```

Пользователю даётся 3 попытки, чтобы открыть замок.

### Правила

1. Пользователь вводит код.
2. Если код правильный, замок открывается.
3. Если код неправильный, пользователь получает сообщение об ошибке.
4. Если пользователь вводит вместо числа текст, необходимо обработать `FormatException`.
5. Каждая попытка расходует одну попытку, даже если пользователь ввёл текст вместо числа.
6. После трёх неудачных попыток замок блокируется.

### Используйте

- `while` или `do-while`;
- `try...catch`;
- `finally`;
- `break`.

В блоке `finally` выведите:

```text
Проверка попытки завершена.
```

Именно в `finally` увеличивайте счётчик использованных попыток.

**Пример работы:**

```text
===== ЭЛЕКТРОННЫЙ ЗАМОК =====

Введите код: 1111
Неверный код.

Проверка попытки завершена.

Введите код: hello
Ошибка: необходимо ввести число.

Проверка попытки завершена.

Введите код: 1234
Замок открыт!

Проверка попытки завершена.
```

### Дополнительное усложнение

Если все попытки закончились, выведите:

```text
Замок заблокирован!
```

## Задание 4 — Контроль громкости аудиоплеера

Представьте, что вы разрабатываете аудиоплеер.

У него есть параметр громкости:

```cs
int volume = 50;
```

Громкость может находиться в диапазоне от `0` до `100`.

Создайте метод:

```cs
void SetVolume(int volume)
```

Метод должен устанавливать новую громкость.

Однако существуют ограничения:

- громкость не может быть меньше 0;
- громкость не может быть больше 100.

Если пользователь пытается установить недопустимое значение, метод должен самостоятельно выбросить исключение через `throw`.

Например:

```cs
throw new ArgumentOutOfRangeException(
    "volume",
    "Громкость должна находиться в диапазоне от 0 до 100."
);
```

### Требования

1. Получить от пользователя новую громкость.
2. Передать её в `SetVolume()`.
3. Если значение неправильное, выбросить исключение.
4. Обработать исключение через `catch`.
5. Если громкость установлена успешно, вывести новое значение.

**Пример успешной операции:**

```text
Введите громкость: 75

Громкость установлена: 75%
```

**Пример ошибки:**

```text
Введите громкость: 150

Ошибка: громкость должна находиться в диапазоне от 0 до 100.
```

### Дополнительное усложнение

Добавьте обработку `FormatException`, если пользователь вместо числа вводит текст.

## ⭐ Задание 5 — Система продажи билетов в парк аттракционов

Представьте, что вы разрабатываете программу для автоматической продажи билетов в парк развлечений.

В парке есть три аттракциона:

```text
1 — Американские горки (700 рублей)
2 — Колесо обозрения (300 рублей)
3 — Карусель (200 рублей)
```

Пользователь должен ввести:

- имя;
- возраст;
- рост;
- номер аттракциона.

### Правила покупки

**Американские горки:**

- минимальный возраст — 12 лет;
- минимальный рост — 140 см.

**Колесо обозрения:**

- минимальный рост — 100 см.

**Карусель:**

- ограничений по возрасту и росту нет.

### Часть 1. Создание метода

Создайте метод:

```cs
int BuyTicket(int age, int height, int attractionNumber)
```

Метод должен:

1. Проверить корректность возраста.
2. Проверить корректность роста.
3. Проверить существование выбранного аттракциона.
4. Проверить, подходит ли посетитель по возрасту и росту.
5. Вернуть стоимость билета, если все проверки пройдены.

Если обнаружено нарушение, метод должен самостоятельно выбросить исключение через `throw`.

Используйте следующие типы исключений:

- `ArgumentOutOfRangeException` — если возраст или рост имеют недопустимое значение;
- `ArgumentException` — если выбран несуществующий аттракцион;
- `InvalidOperationException` — если посетителю нельзя пользоваться выбранным аттракционом по правилам парка.

### Часть 2. Обработка исключений

В `Main()` вызовите `BuyTicket()` внутри `try`.

Предусмотрите отдельные блоки `catch` для разных типов исключений.

**Важно:** `ArgumentOutOfRangeException` наследуется от `ArgumentException`, поэтому обработчик `ArgumentOutOfRangeException` необходимо разместить раньше обработчика `ArgumentException`.

Если покупка прошла успешно, выведите билет:

```text
======= БИЛЕТ =======

Посетитель: Alex
Возраст: 16
Рост: 175 см

Аттракцион: Американские горки
Стоимость: 700 рублей

Статус: Билет оформлен!

=====================
```

Если возникла ошибка, выведите соответствующее сообщение.

Например:

```text
Ошибка: для американских горок необходимо иметь рост не менее 140 см.
```

### Часть 3. Блок finally

Вне зависимости от результата покупки программа должна вывести:

```text
Обработка заявки завершена.
Спасибо за посещение нашего парка!
```

Для этого используйте `finally`.

### Дополнительное усложнение

Добавьте возможность покупки нескольких билетов.

Пользователь вводит количество билетов, а программа рассчитывает общую стоимость.

Если пользователь пытается купить меньше одного билета или больше пяти, выбрасывайте `ArgumentOutOfRangeException`.
