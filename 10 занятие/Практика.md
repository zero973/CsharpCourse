## Задание 1 — Корзина интернет-магазина

Представьте, что вы разрабатываете корзину покупок для интернет-магазина.

Создайте коллекцию:

```cs
List<string> cart = new List<string>();
```

В корзине будут храниться названия товаров.

Реализуйте следующие операции:

1. Добавление товара в корзину.
2. Удаление товара из корзины.
3. Поиск товара по названию.
4. Вывод всех товаров.
5. Вывод количества товаров в корзине.

Используйте:

- `Add()`;
- `Remove()`;
- `Contains()`;
- `Count`.

### В `Main()`:

Добавьте несколько товаров:

```text
Ноутбук
Мышь
Клавиатура
Монитор
Наушники
```

Затем:

1. Удалите мышь.
2. Проверьте, находится ли монитор в корзине.
3. Добавьте ещё один товар.
4. Выведите содержимое корзины.

**Пример результата:**

```text
======= КОРЗИНА =======

1. Ноутбук
2. Клавиатура
3. Монитор
4. Наушники

Количество товаров: 4

=======================
```

**Дополнительное усложнение**

Реализуйте меню:

```text
1 — Добавить товар
2 — Удалить товар
3 — Найти товар
4 — Показать корзину
0 — Выход
```

Программа должна продолжать работу, пока пользователь не выберет выход.

## Задание 2 — Отмена последнего действия

Представьте, что вы разрабатываете простой графический редактор.

Пользователь выполняет различные действия:

```text
Нарисовал круг
Нарисовал квадрат
Изменил цвет
Добавил текст
Удалил объект
```

Программа должна запоминать историю действий.

Создайте коллекцию:

```cs
Stack<string> actions = new Stack<string>();
```

Реализуйте следующие операции:

1. Добавить новое действие в историю.
2. Посмотреть последнее действие.
3. Отменить последнее действие.
4. Вывести количество сохранённых действий.

Используйте:

- `Push()`;
- `Pop()`;
- `Peek()`;
- `Count`.

### Пример работы

```text
Добавлено действие: Нарисовал круг
Добавлено действие: Нарисовал квадрат
Добавлено действие: Изменил цвет

Последнее действие: Изменил цвет

Отмена действия: Изменил цвет

Последнее действие: Нарисовал квадрат
```

**Вопрос:**

Почему для реализации отмены последнего действия подходит `Stack`, а не обычный `List`?

## Задание 3 — Очередь в ресторане

Представьте, что вы разрабатываете программу для управления очередью посетителей ресторана.

Создайте коллекцию:

```cs
Queue<string> customers = new Queue<string>();
```

Реализуйте следующие операции:

1. Добавить посетителя в очередь.
2. Обслужить первого посетителя.
3. Посмотреть, кто следующий в очереди.
4. Вывести всех посетителей.
5. Вывести количество ожидающих посетителей.

Используйте:

- `Enqueue()`;
- `Dequeue()`;
- `Peek()`;
- `Count`.

### Пример работы

```text
В очередь добавлен: Иван
В очередь добавлен: Алексей
В очередь добавлен: Мария

Следующий посетитель: Иван

Обслуживаем посетителя: Иван

Осталось в очереди: 2
```

### Важное условие

Перед вызовом `Dequeue()` и `Peek()` необходимо проверять, что очередь не пустая.

Если посетителей нет, выведите:

```text
Очередь пуста!
```

## Задание 4 — Каталог товаров

Представьте, что вы разрабатываете систему поиска товаров интернет-магазина.

У каждого товара есть уникальный артикул и цена.

Создайте коллекцию:

```cs
Dictionary<string, int> products = new Dictionary<string, int>();
```

В качестве ключа используйте артикул товара, а в качестве значения — его цену.

Реализуйте следующие операции:

1. Добавление нового товара.
2. Поиск товара по артикулу.
3. Изменение цены товара.
4. Удаление товара.
5. Вывод всех товаров.

Используйте:

- `Add()`;
- `Remove()`;
- `ContainsKey()`;
- `TryGetValue()`;
- `Count`.

### Пример данных

```text
KB001 → 3000
MS002 → 1500
MN003 → 25000
```

### Пример работы

```text
Введите артикул товара: MS002

Товар найден!
Артикул: MS002
Цена: 1500 рублей
```

Если товар не найден:

```text
Товар с таким артикулом не существует.
```

### Дополнительное усложнение

Реализуйте возможность изменения цены существующего товара.

## Задание 5 — Регистрация на игровой сервер

Представьте, что вы разрабатываете систему регистрации игроков на игровом сервере.

Один игрок может зарегистрироваться только один раз.

Создайте коллекцию:

```cs
HashSet<string> players = new HashSet<string>();
```

Каждый элемент — уникальный никнейм игрока.

Реализуйте следующие операции:

1. Регистрация игрока.
2. Удаление игрока.
3. Проверка регистрации игрока.
4. Вывод всех зарегистрированных игроков.
5. Вывод количества зарегистрированных игроков.

Используйте:

- `Add()`;
- `Remove()`;
- `Contains()`;
- `Count`.

### Пример работы

```text
Регистрация игрока: Alex
Игрок успешно зарегистрирован!

Регистрация игрока: Player123
Игрок успешно зарегистрирован!

Регистрация игрока: Alex
Ошибка! Игрок с таким никнеймом уже зарегистрирован.

Всего игроков: 2
```

**Вопрос:**

Почему здесь лучше использовать `HashSet`, а не `List`?

## Задание 6 — Мини-система управления игровым турниром

Представьте, что вы разрабатываете программу для организации киберспортивного турнира.

В турнире необходимо:

- хранить список всех зарегистрированных игроков;
- не допускать повторную регистрацию;
- формировать очередь участников на матчи;
- хранить результаты игроков;
- запоминать последние действия организатора.

Для этого используйте сразу несколько коллекций:

```cs
List<string> players = new List<string>();

HashSet<string> uniquePlayers = new HashSet<string>();

Queue<string> matchQueue = new Queue<string>();

Dictionary<string, int> scores = new Dictionary<string, int>();

Stack<string> actionHistory = new Stack<string>();
```

### Реализуйте следующие операции

**1. Регистрация игрока**

Добавляет нового игрока в список участников.

Если игрок уже зарегистрирован, повторно добавлять его нельзя.

При успешной регистрации:

- добавить игрока в `List`;
- добавить никнейм в `HashSet`;
- добавить игрока в `Queue`;
- создать запись в `Dictionary` с начальным счётом 0;
- сохранить действие в `Stack`.

**2. Начало матча**

Извлекает первого игрока из очереди.

Если очередь пуста, вывести сообщение:

```text
Нет игроков для участия в матче.
```

**3. Начисление очков**

Пользователь вводит никнейм и количество очков.

Программа должна увеличить счёт игрока в `Dictionary`.

Если игрок не зарегистрирован, вывести сообщение об ошибке.

**4. История действий**

Покажите последнее действие организатора.

Также реализуйте отмену последнего действия в истории: удаление записи из `Stack`.

На этом этапе достаточно отменять только запись истории, фактические изменения данных отменять не требуется.

**5. Просмотр результатов**

Выведите всех участников и их очки.

### Пример

```text
======= ТУРНИР =======

Игроки:
1. Alex
2. Player123
3. Dragon

Очки:

Alex: 150
Player123: 200
Dragon: 100

Игроков зарегистрировано: 3

Последнее действие:
Начислено 100 очков игроку Dragon.

======================
```

**Дополнительное усложнение**

Добавьте операцию удаления игрока из турнира.

При удалении необходимо удалить его из всех соответствующих коллекций.
