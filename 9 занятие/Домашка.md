## Задание 1 — Система игровых персонажей

Представьте, что вы разрабатываете RPG-игру.

В игре существуют разные типы персонажей:

- воин;
- маг;
- лучник.

У всех персонажей есть общие характеристики, но способы атаки отличаются.

### Часть 1. Абстрактный класс

Создайте абстрактный класс:

> GameCharacter

Добавьте свойства:

- `Name` — имя персонажа;
- `Health` — здоровье;
- `Level` — уровень.

Создайте конструктор, принимающий имя, здоровье и уровень.

Создайте абстрактный метод:

> void Attack()

Каждый тип персонажа должен самостоятельно реализовать атаку.

Создайте виртуальный метод:

> virtual void TakeDamage(int damage)

Он должен уменьшать здоровье персонажа на полученный урон.

Здоровье не должно становиться меньше нуля.

Создайте метод:

> void PrintInfo()

Он выводит характеристики персонажа.

### Часть 2. Производные классы

Создайте:

> Warrior : GameCharacter

Свойство:

- `Armor` — броня.

Метод `Attack()` выводит:

```text
Воин атакует мечом!
```

Дополнительно переопределите `TakeDamage()` так, чтобы броня уменьшала получаемый урон.

> Mage : GameCharacter

Свойство:

- `Mana` — количество маны.

Метод `Attack()` выводит:

```text
Маг использует магическое заклинание!
```

После атаки количество маны уменьшается на 10.

> Archer : GameCharacter

Свойство:

- `Arrows` — количество стрел.

Метод `Attack()` выводит:

```text
Лучник выпускает стрелу!
```

После атаки количество стрел уменьшается на 1.

Если стрел или маны недостаточно, персонаж не может атаковать.

### В `Main()`:

1. Создайте воина, мага и лучника.
2. Поместите их в массив `GameCharacter[]`.
3. Вызовите `Attack()` для каждого персонажа.
4. Нанесите каждому персонажу урон через `TakeDamage()`.
5. Выведите характеристики после выполнения операций.

**Дополнительное усложнение**

Добавьте метод:

> void LevelUp()

Он повышает уровень персонажа и увеличивает его максимальные характеристики.

## Задание 2 — Мультимедийный проигрыватель

Представьте, что вы разрабатываете приложение для воспроизведения различных медиафайлов.

Программа должна поддерживать:

- аудиозаписи;
- видеозаписи.

Оба типа файлов умеют воспроизводиться, ставиться на паузу и останавливаться.

### Часть 1. Интерфейс

Создайте интерфейс:

> IPlayable

Добавьте методы:

> void Play()

Запускает воспроизведение.

> void Pause()

Ставит воспроизведение на паузу.

> void Stop()

Останавливает воспроизведение.

### Часть 2. Реализация интерфейса

Создайте класс:

> AudioTrack : IPlayable

Свойства:

- `Title` — название аудиозаписи;
- `Artist` — исполнитель;
- `Duration` — длительность в секундах.

Реализуйте три метода интерфейса.

Пример:

```text
Воспроизводится аудиозапись:
Название: Believer
Исполнитель: Imagine Dragons
```

Создайте класс:

> VideoClip : IPlayable

Свойства:

- `Title` — название видео;
- `Duration` — длительность в секундах;
- `Quality` — качество видео.

Реализуйте три метода интерфейса.

Пример:

```text
Воспроизводится видео:
Название: Обзор игры
Качество: 1080p
```

### В `Main()`:

1. Создайте несколько аудиозаписей.
2. Создайте несколько видеозаписей.
3. Поместите все объекты в массив `IPlayable[]`.
4. С помощью `foreach` вызовите `Play()` для каждого элемента.
5. Затем вызовите `Pause()` и `Stop()`.

**Дополнительное усложнение**

Добавьте интерфейс:

> IDownloadable

С методом:

> void Download()

Реализуйте его только в классе `VideoClip`.

Объясните, почему интерфейс `IDownloadable` необязательно реализовывать в `AudioTrack`.

## ⭐ Задание 3 — Система доставки интернет-магазина

Представьте, что вы разрабатываете систему управления доставками интернет-магазина.

Магазин поддерживает три способа получения заказа:

- стандартная доставка;
- экспресс-доставка;
- самовывоз.

У всех видов доставки есть общие характеристики, но стоимость рассчитывается по-разному.

Кроме того, некоторые виды доставки позволяют отслеживать перемещение заказа.

### Часть 1. Абстрактный класс

Создайте абстрактный класс:

> Delivery

Добавьте свойства:

- `OrderNumber` — номер заказа;
- `Distance` — расстояние доставки в километрах;
- `Weight` — вес заказа в килограммах.

Создайте конструктор, принимающий все три значения.

Создайте абстрактный метод:

> double CalculateCost()

Он должен рассчитывать стоимость доставки.

Создайте виртуальный метод:

> virtual void PrintInfo()

Он выводит номер заказа, расстояние, вес и стоимость доставки.

### Часть 2. Производные классы

Создайте три класса.

> StandardDelivery : Delivery

Стандартная доставка.

Стоимость:

```text
100 + Distance * 10 + Weight * 20
```

> ExpressDelivery : Delivery

Экспресс-доставка.

Стоимость:

```text
300 + Distance * 20 + Weight * 30
```

> PickupDelivery : Delivery

Самовывоз.

Стоимость всегда равна:

```text
0
```

Каждый класс должен самостоятельно реализовать `CalculateCost()`.

### Часть 3. Интерфейс отслеживания

Создайте интерфейс:

> ITrackable

Добавьте метод:

> string GetTrackingStatus()

Метод должен возвращать информацию о текущем статусе доставки.

Реализуйте интерфейс в классах `StandardDelivery` и `ExpressDelivery`.

Например:

```text
Заказ #1001
Статус: Передан курьеру.
```

Для `PickupDelivery` интерфейс реализовывать не нужно, поскольку при самовывозе курьерская доставка отсутствует.

### Часть 4. Работа программы

В `Main()`:

1. Создайте несколько доставок разных типов.
2. Поместите их в массив `Delivery[]`.
3. С помощью `foreach` выведите информацию о каждой доставке.
4. Выведите статусы отслеживания для стандартной и экспресс-доставки.

**Пример:**

```text
======= ЗАКАЗ #1001 =======

Тип: Стандартная доставка
Расстояние: 20 км
Вес: 3 кг

Стоимость: 360 рублей
Статус: Передан курьеру.

===========================


======= ЗАКАЗ #1002 =======

Тип: Экспресс-доставка
Расстояние: 20 км
Вес: 3 кг

Стоимость: 790 рублей
Статус: Заказ в пути.

===========================


======= ЗАКАЗ #1003 =======

Тип: Самовывоз

Стоимость: 0 рублей

===========================
```

### Дополнительное усложнение

Создайте новый класс:

> InternationalDelivery : Delivery

Он должен представлять международную доставку.

Стоимость:

```text
500 + Distance * 30 + Weight * 50
```

Дополнительно реализуйте в нём `ITrackable`.

Добавьте международную доставку в массив `Delivery[]`.

Убедитесь, что для нового класса не потребовалось изменять существующие классы стандартной, экспресс-доставки и самовывоза.
