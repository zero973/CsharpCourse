## Задание 1 — Транспортная компания

Представьте, что вы разрабатываете программу для учёта транспортных средств компании.

Создайте базовый класс:

> Vehicle

У транспортного средства должны быть:

- `Brand` — марка;
- `MaxSpeed` — максимальная скорость.

Создайте конструктор, который принимает марку и максимальную скорость.

Создайте метод:

> virtual void Move()

Он должен выводить сообщение:

```text
Транспортное средство начало движение!
```

Создайте метод:

> void PrintInfo()

Он выводит информацию о транспортном средстве.

### Создание производных классов

Создайте два класса:

> Car : Vehicle

У автомобиля дополнительно должно быть свойство:

- `DoorsCount` — количество дверей.

Переопределите метод `Move()`:

```text
Автомобиль BMW начал движение!
Максимальная скорость: 240 км/ч.
```

> Motorcycle : Vehicle

У мотоцикла дополнительно должно быть свойство:

- `HasSidecar` — наличие коляски.

Переопределите метод `Move()`:

```text
Мотоцикл Yamaha начал движение!
Максимальная скорость: 180 км/ч.
```

### В `Main()`:

1. Создайте автомобиль и мотоцикл.
2. Вызовите для каждого `PrintInfo()`.
3. Вызовите для каждого `Move()`.

**Дополнительное усложнение**

Создайте массив:

```cs
Vehicle[] vehicles
```

Поместите в него автомобиль и мотоцикл.

С помощью `foreach` вызовите `Move()` для каждого элемента массива.

Обратите внимание: хотя все элементы массива имеют тип `Vehicle`, вызываются именно переопределённые методы конкретных объектов.

**Главная цель:** понять, как наследование помогает переиспользовать код, а `virtual` и `override` позволяют разным объектам по-своему реализовывать общее поведение.

## Задание 2 — Геометрические фигуры

Представьте, что вы разрабатываете программу для вычисления площади геометрических фигур.

У вас есть несколько фигур:

- круг;
- прямоугольник;
- треугольник.

У всех фигур есть общее свойство — название, но формула вычисления площади у каждой своя.

### Часть 1. Абстрактный класс

Создайте абстрактный класс:

> Shape

Добавьте свойство:

- `Name` — название фигуры.

Создайте конструктор, принимающий название фигуры.

Создайте абстрактный метод:

> double CalculateArea()

Он должен возвращать площадь фигуры.

Создайте виртуальный метод:

> virtual void PrintInfo()

Он должен выводить название фигуры и результат вычисления её площади.

### Часть 2. Производные классы

Создайте три класса:

> Circle : Shape

Свойство:

- `Radius` — радиус.

Площадь круга:

```text
S = π × R²
```

Для числа π используйте `Math.PI`.

> Rectangle : Shape

Свойства:

- `Width` — ширина;
- `Height` — высота.

Площадь:

```text
S = Width × Height
```

> Triangle : Shape

Свойства:

- `Base` — основание;
- `Height` — высота.

Площадь:

```text
S = Base × Height / 2
```

Каждый класс должен самостоятельно реализовать `CalculateArea()`.

### В `Main()`:

1. Создайте круг, прямоугольник и треугольник.
2. Поместите их в массив `Shape[]`.
3. С помощью `foreach` выведите информацию о каждой фигуре.

**Пример:**

```text
======= ФИГУРЫ =======

Круг
Радиус: 5
Площадь: 78.54

Прямоугольник
Ширина: 10
Высота: 5
Площадь: 50

Треугольник
Основание: 8
Высота: 6
Площадь: 24

======================
```

### Вопросы

1. Почему нельзя создать объект напрямую через `new Shape()`?
2. Почему `CalculateArea()` должен быть абстрактным?
3. Почему все три фигуры можно хранить в массиве типа `Shape[]`?

## Задание 3 — Система уведомлений

Представьте, что вы разрабатываете приложение, которое должно отправлять уведомления пользователям.

Приложение поддерживает три способа отправки уведомлений:

- электронная почта;
- SMS;
- Push-уведомления.

При этом у этих способов нет общего базового класса, но все они умеют отправлять сообщения.

### Часть 1. Интерфейс

Создайте интерфейс:

> INotificationSender

Добавьте метод:

> void Send(string message)

Это контракт, который должны реализовать все классы отправки уведомлений.

### Часть 2. Реализация интерфейса

Создайте три класса:

> EmailSender : INotificationSender

Метод `Send()` должен выводить:

```text
Отправка Email...
Сообщение: Ваш заказ оформлен!
```

> SmsSender : INotificationSender

Метод `Send()` должен выводить:

```text
Отправка SMS...
Сообщение: Ваш заказ оформлен!
```

> PushSender : INotificationSender

Метод `Send()` должен выводить:

```text
Отправка Push-уведомления...
Сообщение: Ваш заказ оформлен!
```

Реальная отправка сообщений не требуется. Достаточно имитировать её через `Console.WriteLine()`.

### В `Main()`:

1. Создайте по одному объекту каждого класса.
2. Поместите их в массив `INotificationSender[]`.
3. Используя `foreach`, вызовите `Send()` для каждого элемента массива.

**Дополнительное усложнение**

Создайте отдельный метод:

> void SendNotification(INotificationSender sender, string message)

Он должен принимать любой объект, реализующий `INotificationSender`, и отправлять уведомление.

Проверьте его работу с тремя разными реализациями.

**Главный вопрос:**

Почему методу `SendNotification()` не нужно знать, отправляет ли объект Email, SMS или Push-уведомление?
