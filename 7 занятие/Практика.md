## Задание 1 — Каталог книг

Представьте, что вы разрабатываете программу для небольшой библиотеки.

Создайте класс:

> Book

У книги должны быть следующие поля:

- название;
- автор;
- количество страниц;
- год издания.

Создайте метод:

> void PrintInfo()

Метод должен выводить информацию о книге:

```text
======= КНИГА =======

Название: Гарри Поттер
Автор: Джоан Роулинг
Страниц: 500
Год издания: 1997

=====================
```

В `Main()`:

1. Создайте два объекта класса `Book` через `new`.
2. Заполните их поля разными значениями.
3. Вызовите `PrintInfo()` для каждого объекта.

**Дополнительное усложнение**

Добавьте метод:

> void ChangeAuthor(string newAuthor)

Метод должен изменять автора книги.

После изменения снова выведите информацию о книге.

**Вопрос для обсуждения:**

Почему изменение автора одной книги никак не влияет на вторую книгу?

## Задание 2 — Интернет-магазин

Представьте, что вы разрабатываете программу для учёта товаров в интернет-магазине.

Создайте класс:

> Product

У товара должны быть свойства:

- `Name` — название;
- `Price` — цена;
- `Quantity` — количество на складе;
- `Category` — категория товара.

Создайте конструктор, который принимает все четыре значения и устанавливает их в свойства объекта.

Создайте методы:

> void PrintInfo()

Выводит информацию о товаре.

> double CalculateTotalPrice()

Возвращает общую стоимость всех товаров на складе.

Формула:

```text
Общая стоимость = Цена × Количество
```

В `Main()`:

1. Создайте три разных товара через конструктор.
2. Выведите информацию о каждом товаре.
3. Для каждого товара вычислите общую стоимость.
4. Выведите общую стоимость всех товаров.

**Пример:**

```text
======= ТОВАР =======

Название: Клавиатура
Цена: 3000
Количество: 5
Категория: Периферия

Стоимость на складе: 15000

=====================
```

**Дополнительное усложнение**

Добавьте метод:

> void IncreasePrice(double percent)

Он должен увеличивать стоимость товара на заданный процент.

Например:

```text
Старая цена: 1000
Увеличение: 20%

Новая цена: 1200
```

## Задание 3 — Игровой персонаж

Представьте, что вы разрабатываете RPG-игру.

Создайте класс:

> Player

У персонажа должны быть свойства:

- `Name` — имя;
- `Level` — уровень;
- `Health` — здоровье;
- `Damage` — сила атаки.

Создайте конструктор, который принимает все характеристики персонажа.

Создайте методы:

> void Attack()

Выводит сообщение:

```text
Arthas атакует!
Урон: 25
```

> void TakeDamage(int damage)

Уменьшает здоровье персонажа на полученный урон.

Здоровье не должно становиться меньше нуля.

> void Heal(int health)

Восстанавливает здоровье персонажа на указанное количество единиц.

> void PrintInfo()

Выводит полную информацию о персонаже.

В `Main()`:

1. Создайте двух персонажей.
2. Вызовите для каждого `Attack()`.
3. Нанесите одному персонажу урон через `TakeDamage()`.
4. Восстановите ему здоровье через `Heal()`.
5. Выведите информацию об обоих персонажах.

**Дополнительное усложнение**

Добавьте метод:

> void LevelUp()

Он должен увеличивать уровень персонажа на 1, а здоровье и урон — на 10%.
