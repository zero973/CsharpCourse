## Задание 1 — Автомобиль

Создайте класс:

> Car

У автомобиля должны быть свойства:

- `Brand` — марка;
- `Model` — модель;
- `Year` — год выпуска;
- `Fuel` — количество топлива в баке.

Создайте конструктор, который принимает все характеристики автомобиля.

Создайте методы:

> void PrintInfo()

Выводит информацию об автомобиле.

> bool Drive(int kilometers)

Метод имитирует поездку на автомобиле.

Правила:

- на каждые 10 километров расходуется 1 литр топлива;
- если топлива недостаточно, поездка не выполняется;
- если поездка успешна, количество топлива уменьшается.

Метод возвращает `true`, если поездка прошла успешно, и `false`, если топлива не хватило.

> void Refuel(double liters)

Метод заправляет автомобиль на указанное количество литров.

В `Main()`:

1. Создайте два автомобиля.
2. Попробуйте совершить поездку на каждом.
3. Заправьте один из автомобилей.
4. Совершите ещё одну поездку.
5. Выведите информацию об автомобилях.

**Пример:**

```text
Автомобиль: BMW X5
Топливо: 50 литров

Поездка: 200 км

Поездка выполнена!
Остаток топлива: 30 литров
```

## Задание 2 — Банковский счёт

Создайте класс:

> BankAccount

У банковского счёта должны быть свойства:

- `Owner` — имя владельца;
- `AccountNumber` — номер счёта;
- `Balance` — баланс.

Создайте конструктор, который принимает имя владельца, номер счёта и начальный баланс.

Создайте методы:

> void Deposit(int amount)

Пополняет счёт на указанную сумму.

> bool Withdraw(int amount)

Пытается снять указанную сумму.

Правила:

- сумма снятия должна быть больше нуля;
- нельзя снять больше денег, чем находится на счёте;
- если операция успешна, метод возвращает `true`;
- если операция невозможна, метод возвращает `false`.

> void PrintInfo()

Выводит информацию о счёте.

В `Main()`:

1. Создайте два банковских счёта.
2. Пополните один из счетов.
3. Попробуйте снять с него деньги.
4. Попробуйте снять сумму, превышающую баланс.
5. Выведите информацию об обоих счетах.

**Дополнительное усложнение**

Добавьте метод:

> void Transfer(BankAccount target, int amount)

Он должен переводить деньги с текущего счёта на другой банковский счёт.

При успешном переводе баланс текущего счёта уменьшается, а баланс второго счёта увеличивается.

## ⭐ Задание 3 — Система управления питомцем

Представьте, что вы разрабатываете небольшую игру, в которой пользователь ухаживает за виртуальным питомцем.

Создайте класс:

> Pet

У питомца должны быть свойства:

- `Name` — имя;
- `Type` — тип животного;
- `Age` — возраст;
- `Hunger` — голод;
- `Energy` — энергия;
- `Happiness` — настроение.

Создайте конструктор, который принимает имя, тип животного и возраст.

Начальные характеристики:

```text
Hunger: 50
Energy: 100
Happiness: 50
```

Создайте методы:

> void Feed()

Кормит питомца.

- голод уменьшается на 20;
- настроение увеличивается на 10.

> void Play()

Играет с питомцем.

- энергия уменьшается на 20;
- настроение увеличивается на 20;
- голод увеличивается на 10.

> void Sleep()

Питомец спит.

- энергия восстанавливается на 30;
- голод увеличивается на 10.

> void PrintInfo()

Выводит всю информацию о питомце.

### Правила

- Голод не может быть меньше 0 или больше 100.
- Энергия не может быть меньше 0 или больше 100.
- Настроение не может быть меньше 0 или больше 100.
- Если энергия равна 0, питомец не может играть.
- Если голод равен 100, питомец отказывается играть.
- Если настроение падает до 0, вывести сообщение, что питомец грустит.

### Работа программы

В `Main()`:

1. Создайте питомца.
2. Выведите его характеристики.
3. Покормите питомца.
4. Поиграйте с ним.
5. Дайте ему поспать.
6. Выведите характеристики после каждого действия.

**Дополнительное усложнение**

Добавьте метод:

> void PassTime()

Он имитирует прохождение одного игрового часа:

- голод увеличивается на 5;
- энергия уменьшается на 5;
- настроение уменьшается на 5.

После каждого часа выводите характеристики питомца.

Попробуйте сделать так, чтобы пользователь мог самостоятельно выбирать действия питомца через меню.
