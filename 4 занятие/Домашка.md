## ⭐ Задание 15 - Поиск товара в каталоге — бинарный поиск

Представьте, что вы разрабатываете программу для поиска товара в интернет-магазине.

У каждого товара есть числовой ID.

Например:

```cs
101
108
125
132
154
178
201
245
...
```

Массив ID уже отсортирован по возрастанию.

Пользователь вводит ID товара.

Программа должна определить, существует ли такой товар в каталоге.

### Часть 1. Обычный поиск

Сначала реализуйте поиск обычным перебором массива.

То есть программа должна последовательно проверять:

```cs
элемент 0
элемент 1
элемент 2
...
```

### Часть 2. Бинарный поиск

Затем самостоятельно реализуйте Binary Search.

**Программа должна**

1. создать отсортированный массив ID;
2. получить ID для поиска;
3. найти его обычным поиском;
4. найти его бинарным поиском;
5. вывести результат.

Например:

```cs
Введите ID товара: 245
Товар найден!

Обычный поиск:
Проверено элементов: 18

Бинарный поиск:
Проверено элементов: 5
```

Если товара нет:

```cs
Введите ID товара: 500
Товар не найден.
```

**Дополнительное усложнение**

Сравните количество проверок для двух алгоритмов на массиве из:

```cs
10 элементов
100 элементов
1000 элементов
10000 элементов
```

Попробуйте объяснить, почему бинарный поиск становится особенно эффективным на больших массивах.
