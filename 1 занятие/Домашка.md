# Задание 1 - Первое сообщение

Напишите программу, которая выводит в консоль:

```cs
Меня зовут (указать своё имя).
Я изучаю C#.
Это моё первое домашнее задание!
```

Каждая фраза должна находиться на отдельной строке.


# Задание 2 - Информация о себе

Создайте переменные:
- name — ваше имя;
- age — ваш возраст;
- city — город, в котором вы живёте;
- height — ваш рост.

Выведите всю информацию в консоль примерно в таком виде:

```cs
Имя: (ваше имя)
Возраст: 15
Город: Москва
Рост: 175.5
```

# Задание 3 - Любимый фильм

Создайте переменные:

- название любимого фильма;
- год его выхода;
- ваша оценка фильма от 0 до 10.

Выведите информацию в консоль.

Например:

```cs
Фильм: Interstellar
Год выхода: 2014
Моя оценка: 10
```


# Задание 4 - Истина или ложь

Создайте три переменные типа bool, которые отвечают на вопросы:

- isStudent — является ли человек студентом;
- likesProgramming — нравится ли ему программирование;
- hasPet — есть ли у него домашнее животное.

Выведите значения всех трёх переменных в консоль.

# Задание 5 - Буква

Создайте переменную типа char, в которой хранится первая буква вашего имени.

Создайте ещё одну переменную типа string, в которой хранится ваше полное имя.

Выведите обе переменные.

После этого попробуйте присвоить переменной char несколько символов и посмотрите, какую ошибку выдаст IDE.

# Задание 6 - Константы

Создайте две константы:

```cs
DaysInWeek = 7
MonthsInYear = 12
```

Создайте переменную myAge и запишите в неё свой возраст.

Выведите количество дней в неделе, количество месяцев в году и свой возраст.

После этого попробуйте изменить одну из констант. Объясните, почему это невозможно.

# Задание 7 - Покупка

В магазине вы купили:

- тетрадь за 80 рублей;
- ручку за 40 рублей;
- карандаш за 25 рублей.

Создайте отдельную переменную для цены каждого предмета.

Рассчитайте общую стоимость покупки и выведите её в консоль.

Результат должен вычисляться с помощью переменных, а не быть записанным напрямую.

# Задание 8 - Треугольник

Создайте три переменные типа double, которые будут хранить длины сторон треугольника:

```cs
a = 5
b = 7
c = 8
```

Рассчитайте и выведите периметр треугольника.

Затем измените значения сторон и проверьте, что программа правильно пересчитывает результат.

# Задание 9 - Время

В сутках 24 часа.

Создайте константу HoursInDay.

Создайте переменную days, содержащую количество дней, например 5.

Рассчитайте, сколько часов содержится в days днях.

Затем создайте переменную hours и рассчитайте, сколько минут содержится в этом количестве часов.

Программа должна самостоятельно получить оба результата.

# Задание 10 - Переменные и присваивание

Создайте три переменные:

```cs
a = 15
b = 25
c = 40
```

Затем измените значения переменных так, чтобы в конце программы получилось:

```cs
a = 25
b = 40
c = 15
```

Исходные значения сразу переписывать нельзя — нужно использовать присваивание и дополнительные переменные.

# ⭐ Задание 11 - Формула

Создайте переменную:

```cs
number = 8
```

Используя арифметические операции, получите число 100.

Можно создавать дополнительные переменные.

Ограничение: нельзя просто написать:

```cs
number = 100;
```

Нужно именно вычислить результат.

# ⭐ Задание 12 - Мини-калькулятор

Создайте две переменные типа double:

```cs
a = 12.5
b = 4
```

Программа должна самостоятельно вычислить и вывести:

- сумму;
- разность;
- произведение;
- результат деления a на b.

После этого измените значения a и b на другие числа и убедитесь, что программа продолжает работать правильно.

Дополнительное условие: каждое выражение должно использовать переменные a и b, а не записанные вручную числа.
